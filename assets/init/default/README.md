# mkpage Starter

You initialized this repository with `mkpage init`.

## Next step

1. Build the site:

```sh
mkpage build --root .
```

2. Open output in `./public`.

3. Edit `content/*.md`, `layouts/page.html`, and `data/projects.json` as needed.

4. Run `mkpage build --root .` after each change.

The starter uses terminal-inspired semantic widgets, accessible navigation, and a
lightweight responsive split-shell layout. JavaScript is optional: all navigation
links and content remain usable without runtime enhancement.
