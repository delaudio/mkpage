# Define the v0.1 product contract

## Owning ADRs

- `adr/0002-define-the-v0-1-product-contract.md`

## Scope

Create the public product-contract document for mkpage v0.1. Cover the product
promise, target users, terminology, input/output expectations, accessibility,
CLI surface, compatibility, comparable projects, explicit non-goals, and open
questions. Do not select implementation technologies or build the CLI.

## Exit criteria

1. Satisfies ADR 0002 acceptance criterion 1: product promise, users, and use
   cases are documented in `docs/product.md`.
2. Satisfies criteria 2–4: terminology, the v0.1 contract, and non-goals are
   explicit and separated.
3. Satisfies criteria 5–7: accessibility guarantees, README-ready copy, and
   open questions are present.
