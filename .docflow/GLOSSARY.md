# Glossary

## Core terms

- **Static site generator (SSG):** a tool that turns source content and configuration into deployable files before request time.
- **TUI-inspired:** informed by terminal interaction and visual patterns; it does not mean emulating a terminal in the browser.
- **Progressive enhancement:** optional JavaScript enriches an already usable HTML experience without becoming a requirement for core content or navigation.
- **Semantic HTML:** markup whose elements communicate the structure and meaning of content to browsers and assistive technologies.
- **Deterministic build:** identical supported inputs and configuration produce equivalent output.
