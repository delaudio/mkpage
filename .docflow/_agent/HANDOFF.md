# Handoff

Read these files in order before editing:

1. `AGENTS.md`
2. `.docflow/CONVENTIONS.md`
3. `.docflow/plan/README.md`
4. `.docflow/_agent/CURRENT_FOCUS.md`
5. `.docflow/INDEX.md`
6. The tail of `.docflow/_agent/WORKLOG.md`
7. The next `.docflow/plan/todo/` item and every ADR it references.

Stop and surface the issue if the verify gate fails, the queue is empty, an item’s ADR is not `Accepted`, or an acceptance criterion is ambiguous.
